🎯 Guessing Game

A simple number guessing game built with Java.

The computer randomly selects a number between 1 and 100, and the player tries to guess it. After each guess, the game provides a hint to help the player find the correct number.

✨ Features

- Random number generation
- User input using "Scanner"
- Hints for higher or lower guesses
- Attempts counter
- Restart the game by running it again
- Simple console-based interface

🛠️ Technologies

- Java
- "Scanner"
- "Random"
- Loops
- Conditional statements

▶️ How to Run

1. Make sure Java is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the program:

javac GuessingGame.java

5. Run the game:

java GuessingGame

🎮 How to Play

Enter a number between 1 and 100.

- If your guess is too low, the game will tell you to try a higher number.
- If your guess is too high, the game will tell you to try a lower number.
- Keep guessing until you find the correct number.
